
# Git-harjoitustyö

## Projektin tarkoitus
Tämän projektin tarkoituksena on harjoitella Git-versionhallintaa ja GitHubin käyttöä Visual Studio Codessa.

## Mitä harjoituksessa tehdään?
- Luodaan GitHub-repositorio.
- Harjoitellaan commit-toimintoa.
- Luodaan uusia haaroja.
- Yhdistetään haaroja.
- Aiheutetaan ja ratkaistaan merge-konflikti.
- Harjoitellaan push- ja pull-toimintoja.
- Luodaan Pull Request GitHubissa.

## Käytetyt työkalut
- Visual Studio Code
- Git
- GitHub

## Mitä opin?
Opin käyttämään Git-versionhallintaa, tekemään committeja, luomaan haaroja sekä ratkaisemaan merge-konflikteja.

## Työn toteutus

### Mitä tein?

Työn aikana loin uuden GitHub-repositorion ja kloonasin
sen Visual Studio Codeen.

Lisäsin README.md-tiedoston ja tein vähintään viisi
committia Source Control -paneelin kautta.

Loin uuden feature-haaran, johon tein muutoksia.
Tämän jälkeen muutin samaa tiedoston kohtaa sekä
main- että feature-haarassa, jolloin syntyi
merge-konflikti.

Ratkaisin merge-konfliktin Visual Studio Codessa
käyttämällä Accept Both -toimintoa.

Harjoittelin myös Push- ja Pull-toimintoja.
Lopuksi loin GitHubissa Pull Requestin ja yhdistin
feature-haaran main-haaraan.
