
# Git-harjoitustyö

## Projektin tarkoitus
Tämän projektin tarkoituksena on harjoitella Git-versionhallintaa ja GitHubin käyttöä Visual Studio Codessa.

## Mitä harjoituksessa tehdään?
- Luodaan GitHub-repositorio.
- Harjoitellaan commit-toimintoa.
- Luodaan uusia haaroja.
- Yhdistetään haaroja.
- Aiheutetaan ja ratkaistaan merge-konflikti.
- Harjoitellaan push- ja pull-toimintoja.
- Luodaan Pull Request GitHubissa.

## Käytetyt työkalut
- Visual Studio Code
- Git
- GitHub

## Mitä opin?
Opin käyttämään Git-versionhallintaa, tekemään committeja, luomaan haaroja sekä ratkaisemaan merge-konflikteja.



## Projektin kuvaus
Tämä on harjoitustyö, jossa opettelen Gitin
ja GitHubin käyttöä.
